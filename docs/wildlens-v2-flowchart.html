Spatial Reference Data (load once → PostGIS)
Reference Layers
  • WDPA — All India PA boundaries. REST API + monthly shapefile. Free.
  • IUCN range maps — Tiger, elephant, lion, leopard, rhino, gharial, vultures, GIB, blackbuck, wolf, florican
  • KBA shapefile — ~900+ Key Biodiversity Areas. ⚠ Pending BirdLife International data agreement
  • FSI ISFR — Official forest cover boundary (authoritative GoI forest layer)
  • ONE boundary — Open Natural Ecosystems (grassland, savanna, shola, scrubland). ⚠ Email NCF + ATREE (Abi Vanak). Interim: MODIS MCD12Q1 grassland+savanna+shrubland minus revenue forest
  • Wasteland Atlas 2019 — NRSC. Free shapefile. Cross-check IUCN ranges before downgrading priority.
  • Agriculture extent — ISRO Bhuvan crop extent + MODIS MCD12Q1 cropland class
  • Above-ground biomass — ESA CCI Biomass (100m) or Spawn et al. 2020
  • Admin boundaries — State + district + village from censusindia.gov.in
  • Corridor metadata — 3 PDFs: MoEF 2023, WTI 2005 "Right of Passage", WII Tiger Status 2022. pdfplumber → PostgreSQL table. WDPA convex hull for Phase 1 polygons.
  • WorldPop — India population grid (100m). worldpop.org, free.

Three Parallel Data Tracks — all feed the same Event Store
Track 1 — News (Reactive, Layer 2)
RSS + Historical Sources → NLP Pipeline
  • Live RSS — V1 sources + 10 regional language feeds (ongoing). V1 runs every 6h.
  • GDELT — BigQuery free tier (1TB/month). Themes: ENV_WILDLIFE, ENV_POACHING, ENV_DEFORESTATION. ~50k–200k India wildlife URLs, 2013–present.
  • Wayback CDX API — Full historical URL inventory per site (DTE, Mongabay, The Hindu, The Wire). 2003–present. Free REST API.
  • Kalpavriksh PAU — Protected Area Update PDFs 2000–2024. Lowest false positive rate. pdfplumber + pytesseract.
  • Factiva/LexisNexis — Pre-2003 if institutional access. The Hindu from 1990, ToI from 1991.

Layer 2: what was REPORTED. Coverage: dense 2010–present · moderate 2003–2009 · sparse pre-2003. Regional language: near-zero before 2015.

Track 2 — Regulatory (Predictive, Layer 1)
Clearances · Courts · Seizure Data
  • PARIVESH — 50k+ forest clearance records (datagovindia pip pkg). Filed months before news. Highest priority regulatory source.
  • NGT + High Courts — ecourts pip package (GPL-3.0)
  • District Courts — Akshit eCourts API (free non-commercial)
  • TRAFFIC Wildlife Trade Portal — wildlifetradeportal.org (register → immediate access). India + focal species filter. CSV export → traffic_seizures table. No API — CSV loader only. Fields: species, product, seizure location, date, transport route, criminal justice outcome.

Layer 1: what was AUTHORISED. Key signal: clearance filed → monitor buffer for satellite loss.

Track 3 — Satellite (Continuous, Layer 3)
Forest Cover · Active Fire · Deforestation Alerts
  • Global Forest Watch — Annual tree cover loss 2001–2024 (30m, UMD/Hansen). Loss by driver: agriculture / fire / urbanisation / forestry. Corridor width + fragmentation via rasterio/scipy.
  • GLAD-L / GLAD-S2 / RADD — Near-real-time weekly deforestation alerts (10–30m)
  • NASA FIRMS API — Active fire alerts within 3–6 hours. MODIS + VIIRS. Free.
  • MODIS MCD64A1 — Monthly burned area (500m). VIIRS VNP64A1 (375m) for better resolution.
  • ESA CCI Biomass — Above-ground biomass raster (100m). Biomass loss = burned area (ha) × density (t/ha).

Layer 3: what ACTUALLY HAPPENED on the ground. Ground truth for gap analysis.

Track 4 — Biological Indicators (DEFERRED — after Tracks 1–3 operational)
eBird Specialist : Generalist Bird Ratio
  • Forest specialists (Great Hornbill, pittas, flycatchers) decline with habitat degradation. Generalists (House Crow, Common Myna) increase. Ratio = habitat quality signal.
  • Compute ratio per PA / corridor per year. Correlate with PARIVESH clearances (L1), GFW forest loss (L3), HWC/poaching events (L2).
  • Key caveat: eBird coverage sparse in remote forest interiors. Must correct for observer effort. Define specialist/generalist list (~50 species) before coding — no standard published list exists.

Novel: no prior system correlates eBird ratio change with regulatory + satellite + news for India. Standalone paper candidate.

★ Core Intelligence Framework
Three-Layer Gap Analysis — The gaps are the signal
The Three Layers
  • L1 Regulatory — what was authorised (PARIVESH / NGT / courts)
  • L2 Reported — what appeared in news / court coverage
  • L3 Satellite — what GFW/FIRMS shows happened on the ground
Gap Signals = Intelligence
  • L3 loss + no L1 → ILLEGAL ENCROACHMENT — cleared with no permit
  • L3 loss + no L2 → UNDERREPORTED DEGRADATION — satellite saw it, no news
  • L1 + no L3 → Clearance not yet executed — keep monitoring buffer
  • L2 + L3 confirm → High-confidence validated event
Fire-Specific Signals
  • Fire L3 + PARIVESH L1 nearby → Arson for land clearing — documented encroachment tactic in Northeast + Central India
  • Same pixel fires ≥2 consecutive years, outside agriculture season → Encroachment pattern flag
  • Fire in ONE + L1 clearance → Land conversion signal

Example: PARIVESH clearance filed (L1) → protest news (L2) → GFW 80ha loss 6 months later (L3) → linked by location + project → complete picture

Phase 1 — NLP Pipeline  ·  Gate: F1 > 0.75 per class required to proceed
Step 1
Relevance Classifier
  • Keyword pre-filter (V1 KEYWORDS / EXCLUDE_KEYWORDS)
  • scikit-learn LogisticRegression + TF-IDF trained on gold standard
  • Removes: lone-wolf attacks, Wolf Prize, plantation drives, urban infra
  • Output: is_wildlife_relevant score
Step 2
Species Extraction
  • spaCy NER + custom wildlife entity ruler
  • Maps common names → scientific names
  • IUCN status lookup from pre-loaded table
  • Handles: "big cat", "pachyderm" → species
Step 3 ★
Species-Constrained Toponym Disambiguation
  • Extract all GPE/LOC candidates via NER
  • For each candidate: geocode → PostGIS ST_Intersects with IUCN range map
  • Score = geographic plausibility × species range overlap
  • Highest-scoring candidate wins
  • Fallback: PA gazetteer → Nominatim (V1 logic)

Patent candidate. "tiger attack" → reject Rajasthan desert, prefer Sundarbans.

Step 4
Event Classifier
  • scikit-learn baseline. Upgrade to fine-tuned DistilBERT if F1 < 0.75
  • 16 event types from gold standard
  • Extracts: casualties, severity, outcome summary
Step 5 ★
Semantic Deduplication
  • sentence-transformers/all-MiniLM-L6-v2 (384-dim)
  • Cluster: same location + species + time window + cosine > 0.85 → one event
  • Select canonical article (highest info density) as primary
Step 6
Ecological Enrichment
  • PostGIS ST_Within → inside_pa, pa_name
  • ST_DWithin(5km) → nearest PA + distance
  • Corridor membership check
  • Habitat type from forest cover raster
  • State + district from admin boundaries

Phase 4 — Five Intelligence Domains

① Human-Wildlife Conflict SDM (Novel ★)

Coverage Audit First
Mandatory Gate Before SDM Build
  • Plot occurrence density per species per state from full 25-year corpus
  • Table: articles per language per state per species
  • Flag states with <10 incidents/species/decade = unreliable baseline (Chhattisgarh, Jharkhand, Arunachal, Nagaland, Mizoram at risk)
  • Validate against WII HWC survey data for Kerala, Karnataka, Assam
  • Quantify % incidents captured only in regional language press — key differentiator
Output: coverage_audit.md in v2/docs/
★ Multi-Species Conflict Risk SDM
10-Algorithm Ensemble · Two-Axis Classification · Time-Calibrated
8 Independent Pipelines
  • Elephant HWC (crop raid, human fatality, property damage)
  • Tiger HWC (livestock kill, human attack near forest edges)
  • Leopard HWC (periurban fringe, scrub-forest)
  • Sloth bear HWC (Northeast + Central India)
  • Himalayan black bear HWC (HP, Uttarakhand, J&K)
  • Sun bear HWC (Northeast — only if >30 occurrences/season)
  • Poaching hotspots (road access + ranger proximity)
  • Wildlife smuggling corridors (TRAFFIC seizure locations)

Each species: separate occurrence dataset, separate predictor extraction, separate biomod2 run, separate output rasters. No combined models. Ever.

Two-Axis Classification
  • Axis 1 — Resource Suitability: IUCN range overlap + GFW forest cover + PA proximity + EVI (MODIS MOD09A1) + KBDI drought index
  • Axis 2 — Human Pressure: WorldPop population + OSM road proximity + MODIS night-lights (DMSP/VIIRS intercalibrated) + PA distance
  • Output: High / Likely / Low / Rare / Avoided zones
10-Algorithm Ensemble (biomd2 R)
  • MaxEnt · Random Forest · GBM · GLM · GAM · BRT · CART · FDA · SRE · MARS
  • Ensemble weighting by TSS. k=5 cross-validation. Gate: TSS > 0.7
  • Time calibration: each occurrence matched to predictors from its specific season + year (Kitratporn & Takeuchi 2020)
  • 4 ensembles per species: resource suitability/wet + /dry, human pressure/wet + /dry
  • Bias correction: Gaussian kernel density → 10,000 background points
  • Schedule: full rebuild annually · seasonal projection quarterly

Extends Kitratporn & Takeuchi 2020 + Chester Zoo/Oxford/WTI 2025 to all-India multi-species NLP-curated system.

② Illegal Encroachment Detection

★ Three-Layer Gap Engine
L3 Forest Loss × L1 Regulatory × L2 News
  • For each GFW loss polygon: spatial join with PARIVESH buffer (L1) and news events (L2)
  • L3 + no L1 within 30-day window + 5km buffer → ILLEGAL ENCROACHMENT ALERT
  • L3 + no L2 within 90 days → UNDERREPORTED DEGRADATION FLAG
  • L1 present + no L3 after 12 months → Clearance not acted on — continue monitoring
  • Alert: GFW loss in PA buffer + no PARIVESH clearance = strongest signal
  • PARIVESH clearance in wildlife corridor = predictive threat alert before any loss

③ Corridor Stress + Integrity Index

Corridor Stress Index
News-derived signal
  • Events per month per corridor (from news track)
  • Types that raise stress: poaching, hwc, habitat-threat, wildlife-crime
  • Output: stress score per corridor, trend direction
Corridor Integrity Index
Satellite-derived signal
  • Corridor width + fragmentation index over time (GFW rasterio/scipy)
  • Annual tree cover loss within corridor buffer
  • Output: integrity score per corridor, trend direction
★ Combined Signal
Stress × Integrity Matrix
  • High stress + declining integrity → ACTIVE COLLAPSE — most urgent
  • High stress + stable integrity → Incident-heavy but not yet degraded
  • Low stress + declining integrity → Silent degradation — check for underreporting
  • Low stress + stable integrity → Healthy corridor

Distinguishes corridors that appear on news vs corridors that are actually degrading.

⑤ Forest Fire Intelligence

Active Detection
NASA FIRMS → Real-time Alerts
  • NASA FIRMS API — MODIS + VIIRS, active fire alerts within 3–6 hours
  • For each active fire alert: immediate classification through 5 reference layers
  • FOREST_FIRE or ONE_FIRE → trigger alert pipeline immediately
  • Biomass loss: burned area (MODIS MCD64A1 / VIIRS VNP64A1) × ESA CCI Biomass density
5-Layer Classification Pipeline (CRITICAL)
Never treat all fires as equivalent
L1 FSI Forest Cover Boundary → FOREST_FIRE · flag + biomass calc
L2 ONE Boundary (grassland / savanna / shola / scrubland) → ONE_FIRE · cross-check IUCN ranges for GIB, blackbuck, wolf, florican
L3 Agriculture Extent (ISRO Bhuvan / MODIS cropland) → Oct–Nov in IGP = AGRICULTURAL_STUBBLE (exclude) · off-season = AGRICULTURAL_SUSPICIOUS
L4 Wasteland Atlas 2019 (NRSC) → Do NOT dismiss. Many pristine habitats are legally "wasteland". Cross-check IUCN ranges.
L5 IUCN Range Map Cross-check (applies to L2 + L4) → Inside range → WASTELAND_IN_RANGE (high priority) · outside → WASTELAND_OUT_OF_RANGE

Only FOREST_FIRE, ONE_FIRE, AGRICULTURAL_SUSPICIOUS, WASTELAND_IN_RANGE enter the intelligence system. Others logged only.

Temporal Pattern
Encroachment Pattern Detection
  • Pixel-wise fire frequency: same location fire ≥2 consecutive years outside agricultural season = encroachment pattern flag
  • Combine with: PARIVESH applications in same buffer, GFW forest loss, news land-conflict reports in same area
  • Fire + PARIVESH clearance in same ONE = strong land conversion signal

RAG Intelligence Engine
Query Event Store → Retrieve Context → LLM Synthesis
Alert Rules
  • Poaching spike in PA (3+ events / 30 days)
  • Same species, multiple deaths, same area <30 days
  • GFW alert in PA buffer + no PARIVESH clearance
  • L3 loss + no L2 news (90-day window)
  • PARIVESH clearance in corridor buffer
  • Fire or ONE fire + adjacent PARIVESH clearance
  • Repeated fire in same pixel, non-agricultural season
  • SDM conflict zone expansion (pixel slope > threshold)

  • Groq free tier (Llama 3.1 70B) during dev
  • RAG mode only — NOT fine-tuned
  • Retrieves events from pgvector by cosine similarity
  • Synthesises plain-English report with source citations
  • Research papers (Phase 3 ext.) feed same RAG pipeline
What gets trained on gold standard
  • scikit-learn relevance classifier
  • scikit-learn event type classifier (→ DistilBERT if F1 < 0.75)
  • LLM is not trained. It is a retrieval + synthesis tool.
