Event Schema

Schema drives all downstream design

Spatial Datasets
Reference Data Assembly (load once into PostGIS)
  • WTI Elephant Corridors — 101 corridors, "Right of Passage" 2nd Ed (2017) + MoEF 2023. Name, states, width, status, connecting PAs. Contact WTI for shapefile.
  • WDPA — World Database of Protected Areas. All Indian PA boundaries. REST API + monthly shapefile. Free.
  • GBIF — ~40M species occurrence records for India. pygbif Python client. Enables species-range scoring for toponym disambiguation ★
  • IUCN range maps — tiger, elephant, lion, leopard, rhino, gharial, vulture…
  • WII Tiger Census — AITE 2022 distribution grids + habitat maps (PDF + shapefiles)
  • District / state boundary GeoJSON · Forest cover raster (Nikunj has FSI downversioned)

Stored as PostGIS layers. WTI corridor shapefile is the single highest-priority acquisition.

Three Parallel Data Tracks — all feed into the same Event Store
Track 1 — News (Reactive)
RSS Article Pipeline
  • Same RSS sources as V1 + regional feeds
  • NLP extraction: species, location, event type, severity
  • Deduplication: same incident → one event record
  • Spatial join: PA/corridor enrichment via PostGIS

Tells you what was REPORTED — Layer 2 of the three-layer model

Track 2 — Regulatory (Predictive)
Court Cases · Forest Clearances · NGT Verdicts
  • PARIVESH — forest clearance applications & decisions (data.gov.in API, 50k+ records)
  • NGT — National Green Tribunal orders (ecourts library, High Courts)
  • E-Courts India — District + High Court judgments pan-India (Akshit's API, free non-commercial)
  • WCCB — Wildlife Crime Control Bureau seizure data
  • Structured parse: case_number, case_status, forest_area_ha, clearance_type, verdict_summary, project_location

Tells you what was AUTHORISED — Layer 1. Key: clearances filed months before news coverage or satellite detection.

Track 3 — Spatial / Remote Sensing (Continuous)
Forest Cover Change · GFW
  • Global Forest Watch — primary spatial source (REST API, free)
  • Annual tree cover loss 2001–2024 (30m, UMD/Hansen)
  • Near-real-time deforestation alerts: GLAD-L, GLAD-S2, RADD (weekly, 10–30m)
  • Loss by driver: agriculture / fire / urbanization / forestry
  • Corridor width & fragmentation from GeoTIFF raster (rasterio/scipy)
  • Secondary: FSI ISFR (official GoI numbers), LULC via Bhuvan WMS

Tells you what ACTUALLY HAPPENED — Layer 3. Ground truth.

★ Core Analytical Framework
Three-Layer Gap Analysis — Where the Intelligence Lives
The Three Layers
  • L1 Regulatory — what was authorised (PARIVESH/NGT/courts)
  • L2 Events — what was reported (news + court coverage)
  • L3 Ground truth — what satellite shows happened (GFW)
The Gaps = Intelligence
  • L3 loss + no L1 → ILLEGAL ENCROACHMENT — cleared with no permit ever filed
  • L3 loss + no L2 → UNDERREPORTED DEGRADATION — satellite saw it, no news article ever wrote about it
  • L1 exists + no L3 → Clearance granted but not yet acted on — keep monitoring
  • L2 + L3 confirm → High-confidence validated event

Example lifecycle: PARIVESH clearance filed (L1) → news reports protest (L2) → GFW detects 80ha loss 6 months later (L3) → all three linked by location + project name → complete picture

Phase 1 — Article Ingestion & Filtering (Track 1 detail)
Input
RSS Feed Fetch
  • Same sources as V1 (+ regional feeds)
  • Deduplicate by URL before processing
  • Store raw article text, not just title
Filter
Relevance Classification
  • Keyword pre-filter (same as V1)
  • ML classifier trained on gold standard
  • Removes: lone-wolf terrorism, disease outbreaks, urban infra, plantation drives
  • Output: is_wildlife_relevant score
Text Extraction
Full Article Fetch
  • Fetch full article body (not just RSS excerpt)
  • Strip HTML, keep first 2000 chars
  • Store headline + body + date + source

Full text is needed for accurate NER & species extraction

Phase 2 — Event Extraction (the hard part)
NER
Species Extraction
  • spaCy + custom species gazetteer
  • Maps common names → scientific names
  • Looks up IUCN status from pre-loaded table
  • Handles: "big cat", "pachyderm", "great apes" → species
Location
Species-Constrained Toponym Disambiguation
  • Extract all GPE/LOC candidates via NER
  • For each candidate: geocode → check overlap with IUCN range map
  • Score = geographic plausibility × species range overlap
  • Select highest-scoring candidate
  • Fallback: gazetteer → geocoder (V1 logic)

Example: "tiger" → reject Rajasthan desert, prefer Sundarbans/Corbett

Classification
Event Type + Outcome
  • Types: poaching, hwc, mortality, sighting, discovery, conservation_action, habitat_threat, policy, research
  • Extracts: casualties (human/animal), severity, outcome summary
  • Classifier trained on gold standard labels
▼
Deduplication
Event Clustering (Same Incident → One Event)
  • Sentence embeddings (sentence-transformers) for semantic similarity
  • Cluster articles: same location + same species + same time window + high similarity → one event
  • Example: 8 articles about Rajouri forest fires → 1 event with 8 source_articles
  • Select canonical article (highest info density) as primary

Key metric: how many V1 duplicate pins does this eliminate?

Ecological Enrichment
Spatial Join with Reference Data
  • Point-in-polygon: is location inside a PA? Which one?
  • Buffer 5km: nearest PA name + distance
  • Corridor membership check
  • Habitat type from forest cover raster
  • State + district from admin boundaries

All done with PostGIS ST_Within, ST_DWithin queries

Phase 3 — Event Store (PostgreSQL + PostGIS)
Storage
Structured Event Database (all three tracks unified)
events table
  • event_id (UUID)
  • event_type, event_subtype
  • source_track (news / regulatory / satellite)
  • location (PostGIS POINT)
  • inside_pa, pa_name, corridor_name
  • event_date, reported_date
  • severity, outcome_summary
regulatory table
  • case_number, case_status
  • forest_area_ha, clearance_type
  • verdict_summary, project_name
forest_cover table
  • polygon_id (PA or corridor)
  • year, loss_ha, loss_driver
  • corridor_width_m, fragmentation_index
  • alert_type (GLAD/RADD)
event_species table
  • event_id, species_common, scientific_name, iucn_status, count
event_articles table
  • event_id, url, headline, source, published
Analytics
Corridor Stress Index + Corridor Integrity Index
  • Stress index — events/month per corridor (from news track)
  • Integrity index — corridor width + connectivity trend (from GFW track)
  • Combined: high stress + declining integrity = corridor in active collapse
  • High stress + stable integrity = pressure but still intact
  • Low stress + declining integrity = underreported degradation

"Panna–Bandhavgarh: elevated HWC + 12% width loss this year = active collapse"

Phase 4 — Intelligence Layer
RAG Engine
Natural Language Reports
  • Query the event store with structured filters
  • Retrieve relevant events as context
  • LLM synthesises into plain-English report
  • Example: "Summarise elephant HWC in Kerala in 2026"
  • Cites source articles

Uses local/open-source LLM to keep cost = zero

Query API
Advanced Search Interface
  • Natural language: "all tiger incidents in Madhya Pradesh 2025"
  • Structured: filter by species / event_type / PA / date range / severity
  • Spatial: "events within 50km of Kaziranga"
  • Export: CSV / GeoJSON
Alerts
Threshold Monitoring
  • Poaching spike in a PA → flag
  • Same species, multiple deaths, same area < 30 days → flag
  • Corridor stress index threshold breach → flag
  • GFW deforestation alert fires in PA buffer → cross-check PARIVESH — no clearance found = illegal encroachment alert
  • L3 satellite loss with no L2 news coverage → underreported degradation flag
  • PARIVESH clearance granted in wildlife corridor → predictive threat alert before any news
  • Weekly digest email (optional)

Publication & IP Strategy
★ Patent Candidate 1
Species-Constrained Toponym Disambiguation
Score NER location candidates by GBIF species occurrence density + IUCN range map overlap as ecological plausibility prior. No prior NLP system uses species ranges to disambiguate place names.

Consult Indian patent attorney after paper acceptance.

★ Novel Contribution 2
Three-Layer Ecological Gap Analysis
Cross-referencing regulatory (L1: PARIVESH/NGT/courts) + news events (L2) + satellite forest cover (L3: GFW) to surface illegal encroachment and underreported degradation. Gaps between layers = intelligence no single source can provide.

First system to unify all three data streams for Indian wildlife.

Publication Target
Methods in Ecology and Evolution
Framing: domain-expert-driven pipeline where ecological knowledge (range maps, PA topology, corridor stress, regulatory data) constrains every stage. Three data tracks + gap analysis = ecological intelligence, not generic NLP. Evaluated against gold standard dataset (Phase 0).
V1 stays untouched
V1 / V2 Separation
V1 at wildlens.in serves journalists and general public. V2 is a parallel research system — separate codebase, separate database, separate URL. Share only the spatial reference datasets.
