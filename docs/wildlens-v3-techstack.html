Track 1 — News & Historical Text Ingestion
Live RSS
feedparser
pip install feedparser
Parse RSS/Atom feeds from all V1 sources + regional feeds. Returns headline, URL, published date, summary.
Full Article Text
trafilatura
pip install trafilatura
Fetch and extract clean article body from any URL. Strips ads, nav, boilerplate. Better than BeautifulSoup for news sites.
Historical 2013–present
google-cloud-bigquery
pip install google-cloud-bigquery
Query GDELT dataset for India wildlife URLs using ENV_WILDLIFE / ENV_POACHING / ENV_DEFORESTATION theme codes. Free tier: 1 TB/month.
Account at console.cloud.google.com — no credit card if under free tier.
Historical 2003–present
requests (CDX API)
pip install requests
Query Wayback Machine CDX index for full URL history of DTE, Mongabay, The Hindu, The Wire. No auth needed. Returns all archived article URLs per site.
GET web.archive.org/cdx/search/cdx?url=downtoearth.org/news/wildlife/*&output=json
PAU PDFs — text layer
pdfplumber
pip install pdfplumber
Extract text from Kalpavriksh Protected Area Update PDFs that have a text layer (2010+ issues). Page-by-page extraction, handles tables.
PAU PDFs — scanned
pytesseract + Tesseract
pip install pytesseract  ·  apt install tesseract-ocr
OCR for older PAU issues (2000–2009) that are scanned images. Use eng language model. Render PDF pages to images first with pdf2image.
Also install: pip install pdf2image Pillow
If institutional access
Factiva / LexisNexis
University subscription — XML export
The Hindu from 1990, Times of India from 1991. Export structured XML per article. Covers pre-2003 gap that CDX and GDELT cannot fill.
Track 2 — Regulatory Ingestion (PARIVESH · NGT · Courts)
PARIVESH / data.gov.in
datagovindia
pip install datagovindia
Official Python client for data.gov.in REST API. Pulls 50k+ environment clearance records from PARIVESH 2.0. Returns project name, state, district, forest area (ha), clearance status.
Free API key at data.gov.in. For Forest Clearance (FC) and Wildlife Clearance (WL), scrape PARIVESH portal directly — not on data.gov.in.
NGT · High Courts
ecourts
pip install ecourts
Open-source Python library (GPL-3.0) for hcservices.ecourts.gov.in. Search by Act (Wildlife Protection Act, Forest Conservation Act). Covers all High Courts.
High Courts only. Single-threaded by design (polite scraping). Does not cover District Courts or Supreme Court.
District + High Courts
requests (Akshit eCourts API)
pip install requests  ·  Free API key
Third-party REST wrapper (akshit-me.gitbook.io/e-courts-india-api). Pan-India case search including District Courts. Returns case status, orders, judgments. Free non-commercial.
PDF Orders
pymupdf (fitz)
pip install pymupdf
Fast PDF text extraction for NGT orders and court judgments. Better than pdfplumber for large multi-page legal PDFs. Extract text, then run spaCy NLP for location/species/outcome.
Track 3 — Forest Cover & Spatial Analysis (GFW)
GFW API
requests
pip install requests  ·  Free GFW account
POST a polygon GeoJSON + SQL query to GFW REST API. Returns annual tree cover loss 2001–2024, loss by driver, near-real-time GLAD/RADD deforestation alerts.
API key at globalforestwatch.org — expires annually, renew free.
Raster Analysis
rasterio
pip install rasterio
Read GFW tree cover GeoTIFF rasters. Clip to corridor/PA polygon, compute patch statistics. Used to measure corridor width at narrowest point and fragmentation index.
Spatial Metrics
numpy · scipy · scikit-image
pip install numpy scipy scikit-image
Compute fragmentation index (patch size distribution), edge density (perimeter/area), corridor width (morphological thinning on binary raster). Used for corridor integrity index.
Vector Geometry
shapely · geopandas
pip install shapely geopandas
Polygon operations in Python — buffer zones, intersections, point-in-polygon checks. Used before PostGIS queries and for IUCN range map overlap scoring.
Track 4 — Biological Indicators · eBird (Planned)
eBird Data
ebird-api
pip install ebird-api  ·  Free key at ebird.org/api/keygen
Fetch eBird checklists by PA boundary and year. Returns species list, observation counts, observer effort (hours, distance). Basis for specialist:generalist ratio computation.
Species Classification
pandas
pip install pandas
Load custom Indian forest specialist / generalist species list (CSV). Join against eBird observations. Aggregate ratio per PA per year. Normalise by observer effort (checklists, hours).
Correlation Analysis
scipy.stats
pip install scipy
Spearman rank correlation between specialist:generalist ratio and GFW forest loss / PARIVESH clearance count / WildLens event density — per PA per year. Non-parametric, handles non-normal distributions.
NLP Pipeline — All Text Tracks Feed Through Here
NER
spaCy en_core_web_trf
pip install spacy  ·  python -m spacy download en_core_web_trf
Transformer-based NER model. Extracts GPE/LOC entities (location), plus ORG/PERSON where relevant. Same model as V1 pipeline. Applied to all text tracks.
Heavy download (~500MB). Cache in GitHub Actions with actions/cache@v4 keyed on requirements hash.
Species Extraction
Custom gazetteer (CSV)
data/species_gazetteer.csv — no install
Maps common names → scientific name + IUCN category. Handles colloquials: "big cat" → Panthera, "pachyderm" → elephant. Loaded as dict at startup. Fast O(1) lookup after tokenisation.
★ Toponym Disambiguation
shapely + PostGIS + IUCN range maps
pip install shapely psycopg2-binary
For each NER location candidate: geocode → check overlap with IUCN range map for the extracted species. Score = range overlap area. Highest-scoring candidate wins. Novel contribution.
Event Classification
scikit-learn
pip install scikit-learn
Text classifier (TF-IDF + LogReg or fine-tuned BERT) trained on gold standard annotations. Predicts event_type across 16 classes. Outputs class + confidence score.
★ Deduplication
sentence-transformers
pip install sentence-transformers
Semantic embeddings for each article. Cosine similarity clustering: articles within same location × same species × same 7-day window → one event record. Eliminates duplicate pins from multi-outlet coverage.
Spatial Reference Layers — Load Once into PostGIS
PA Boundaries
WDPA Shapefiles
protectedplanet.net — monthly shapefile download
World Database of Protected Areas. All Indian PA boundaries with attributes (name, IUCN category, area, year established). Load into PostGIS as reference layer for ST_Within queries.
Elephant Corridors
WTI GeoJSON (101 corridors)
Contact WTI — no public download
"Right of Passage" 2nd Ed (2017) + MoEF 2023. Attributes: name, states, width (narrowest), status, connecting PAs. Email Upasana Ganguly at WTI for shapefile. Highest-priority static layer.
Species Ranges
IUCN Red List Shapefiles
iucnredlist.org/resources/spatial-data-download
Species distribution polygons for tiger, elephant, lion, leopard, rhino, gharial, vulture species. Used for toponym disambiguation scoring. Free download with registration.
Admin Boundaries
India GeoJSON (states + districts)
datameet/maps — GitHub, free
State and district boundary polygons for India. Used for stateProvince and county enrichment via PostGIS ST_Within. datameet/maps on GitHub has clean district-level GeoJSON.
Event Store — PostgreSQL + PostGIS
Database
PostgreSQL + PostGIS
apt install postgresql postgis  ·  CREATE EXTENSION postgis;
Main event database. PostGIS adds geometry column type and spatial functions (ST_Within, ST_DWithin, ST_Intersects) for all PA/corridor membership queries. Stores events, regulatory, forest_cover, species, articles tables.
ORM
SQLAlchemy + GeoAlchemy2
pip install sqlalchemy geoalchemy2 psycopg2-binary
Python ORM for PostgreSQL. GeoAlchemy2 adds PostGIS geometry type support. Define event schema as Python classes — avoids raw SQL for CRUD operations.
Migrations
Alembic
pip install alembic
Schema version control for PostgreSQL. Generate migration scripts when event schema changes. Rollback-safe. Works with SQLAlchemy models.
Vector Search
pgvector
apt install postgresql-pgvector  ·  CREATE EXTENSION vector;
PostgreSQL extension for storing and querying vector embeddings. Used by RAG engine to find semantically similar events. Keeps everything in one database — no separate vector store needed.
Intelligence Layer — RAG · Query API · Alerts
Local LLM
Ollama
ollama.com — free, runs locally
Run open-source LLMs locally. Zero API cost. Recommended models: Mistral 7B (fast, good reasoning) or Llama 3.1 8B (strong instruction following). Powers natural language report generation.
GPU recommended but runs on CPU. 8GB RAM minimum for 7B models.
RAG Framework
LlamaIndex
pip install llama-index llama-index-vector-stores-postgres
Orchestrates retrieval-augmented generation. Query → retrieve relevant events from pgvector → pass as context to Ollama LLM → return cited plain-English report. Supports structured filter + semantic search hybrid.
Query API
FastAPI
pip install fastapi uvicorn
REST API exposing event store queries: filter by species / event_type / PA / date range / severity / spatial radius. Also serves RAG chat endpoint. Lightweight, async, auto-generates OpenAPI docs.
Scheduling
GitHub Actions (existing)
Already set up in .github/workflows/
Track 1 RSS pipeline runs every 6h (existing V1 cron). V2 pipeline extends this with NLP, deduplication, PostGIS enrichment. GFW alert polling added as separate weekly workflow.
Interface — Map · Dashboard · Chat
Map
Leaflet.js + MarkerCluster
CDN — same as V1
Interactive map. One pin per event (not per article). Pin colour = event_type. PA boundary overlay. Corridor stress heat layer. Inherits V1 tile layer and cluster plugin.
Dashboard
Plotly.js
CDN — cdn.plot.ly/plotly-latest.min.js
Interactive charts: event counts by species/PA/type, HWC trend by state, corridor stress index panel, species:generalist ratio trend (Track 4). Richer than Chart.js for multi-axis ecological data.
Chat Interface
Vanilla HTML/JS → FastAPI
No framework — plain fetch() calls
Simple chat UI that POSTs queries to FastAPI RAG endpoint. Streams response tokens. Displays cited source articles. No React/Vue — keeps bundle zero and works on GitHub Pages static hosting.
Frontend
GitHub Pages
Free — already set up at wildlens.in
Static files (map, dashboard, chat UI) served from docs/v2/. V1 at wildlens.in stays completely untouched. JavaScript fetch() calls hit api.wildlens.in for queries.
Hosting Guide — Where Everything Runs
ARCHITECTURE
wildlens.in ──────────────→ GitHub Pages (static frontend — free, already live)
api.wildlens.in ──────────→ Cloud server (FastAPI + PostgreSQL + LLM)
One A record in GoDaddy: api.wildlens.in → server IP. That's the only DNS change needed.
What runs where:
GitHub Actions — data ingestion pipeline (all 4 tracks), runs every 6h. Writes to PostgreSQL on your server AND to docs/news.json for V1.
Cloud server — PostgreSQL + PostGIS + pgvector (event store) · FastAPI (query API + RAG endpoint).
LLM — Groq API (free cloud) or Ollama (on server, needs more RAM). Used only for RAG report generation — not trained, not fine-tuned.
GitHub Pages — static frontend only. Map, dashboard, chat UI. fetch() calls hit api.wildlens.in.
LLM is not trained — it is used in RAG mode.
What IS trained on your gold standard data: the event classifier (scikit-learn) and relevance classifier — small, fast, no GPU needed.
The LLM only synthesises reports from retrieved events passed as context. Domain knowledge lives in the database, not the model weights. This is the whole point of RAG — no fine-tuning required.
▶ Free Tier — Use During Phase 1–2 (Development & Validation)
Database
Supabase
supabase.com — free forever tier
Managed PostgreSQL with PostGIS ✓ and pgvector ✓ built in. 500MB storage — sufficient for events + Indian PA spatial layers at research scale. No server to manage, just connect via connection string.
Load only Indian PAs from WDPA (not global) to stay within 500MB. Upgrade to Pro ($25/mo) if storage exceeded.
API
Render
render.com — free tier (750 hrs/month)
Hosts FastAPI. Free tier spins down after 15min inactivity — first request after idle takes ~30s to wake. Acceptable for a research tool with occasional use. No sleep if you upgrade ($7/mo).
LLM
Groq API
console.groq.com — free API key
Llama 3.1 70B free of charge. ~14,400 requests/day — far more than a research tool will use. Significantly more capable than a 7B model on a small server. pip install groq.
Data leaves your machine. Fine for public wildlife news. Would reconsider for sensitive unpublished field data.

DEPLOY SEQUENCE (when ready)
Free path:
1. Create Supabase project → enable PostGIS + pgvector extensions → run Alembic migrations
2. Load spatial reference layers (ogr2ogr → Supabase connection string)
3. Deploy FastAPI to Render → set DB connection string as env var
4. Get Groq API key → set as env var in Render
5. Add SUPABASE_URL + GROQ_API_KEY as GitHub Actions secrets → pipeline inserts events into Supabase
6. Add api.wildlens.in CNAME in GoDaddy → Render URL
7. Deploy V2 frontend to docs/v2/ → live on wildlens.in/v2

Paid path (Hetzner CX32):
1. Create Hetzner server → SSH in → install PostgreSQL + PostGIS + pgvector + FastAPI + Ollama + nginx + certbot
2. Pull Ollama model: ollama pull mistral
3. Set up systemd service for FastAPI (auto-restart on reboot)
4. certbot → free SSL for api.wildlens.in
5. Add A record in GoDaddy: api.wildlens.in → Hetzner IP
6. Add server SSH key + DB credentials as GitHub Actions secrets
